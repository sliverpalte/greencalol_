# claude-content-skills 한국어 안내

이 스킬은 리본랩스가 한국어로 새로 쓴 안내 스킬이다. claude-content-skills 의 스킬 파일은 들어 있지 않다. 원저자 저장소는 `https://github.com/Ootto-AI/claude-content-skills` (MIT)이고, 리본랩스는 Ootto·앤트로픽과 제휴 관계가 아니다. 내용은 2026-11-09 에 저장소 README · 스킬 파일 · 설치 스크립트를 읽어 확인했다(그날 skills 폴더 55개). 판이 바뀌었을 수 있으니 설치 전에 저장소를 다시 보고, 다르면 저장소를 따른다.

## 무엇인가

인스타 콘텐츠 일을 나눠 맡는 클로드 스킬 묶음이다. 각 스킬은 글로 된 지시문이라 코드가 돌지 않는다. 사용자가 부르면 클로드가 그 지시대로 글을 써 준다.

자주 쓰는 다섯과 묶음 하나:

- `reel-builder` — 아이디어 하나를 바로 찍을 수 있는 릴스 설계로 바꾼다. 박자별 대본, 화면 글자, 장면, 속도 표시, 캡션까지. 영상을 직접 렌더하지는 않는다.
- `carousel-builder` — 스크롤을 멈추는 첫 장부터 저장하고 싶은 마지막 장까지 장별 문구를 쓴다.
- `caption-and-hashtags` — 캡션, 해시태그 묶음, 첫 댓글을 쓴다. 더 보기 전에 보이는 첫 줄을 따로 다듬는다.
- `bio-profile-optimizer` — 소개글·이름 칸·고정 릴스 순서를 다시 써서 들어온 사람이 팔로우하게 한다.
- `comment-responder` — 댓글마다 공개 답글을 달고 요청한 자료를 DM 으로 보내는 흐름을 짠다. 실제로 계정에 자동 답글·DM 을 보내려면 인스타 연결 도구가 따로 있어야 한다. 이 묶음만으로는 계정에 아무것도 올리지 않는다.
- `content-factory` — 위 일을 순서대로 돌리는 묶음 스킬이다. 뜬 포맷 찾기 → 분석 → 훅 → 대본 → 제작 설계 → 캡션 → 게시 준비 → 댓글 응대 순서다. 게시는 사용자가 직접 한다.

## 설치를 부탁받으면

아래 순서를 지킨다. 허락 없이 고치지 않는다.

1. git 이 있는지 확인한다(`git --version`). 없으면 알리고 대신 설치할지 묻는다.
2. 저장소를 임시 폴더에 받는다. 사용자 폴더는 아직 건드리지 않는다.

```bash
git clone --depth 1 https://github.com/Ootto-AI/claude-content-skills.git "$TMPDIR/ccs"
```

윈도우 파워셸이면 `git clone --depth 1 https://github.com/Ootto-AI/claude-content-skills.git "$env:TEMP\ccs"` 를 쓴다.

3. `skills/` 아래 폴더 이름과 `~/.claude/skills/` 에 이미 있는 폴더 이름을 대조해 **겹치는 이름을 먼저 보여 준다**. `humanizer` · `agent-reach` 처럼 흔한 이름이 이미 있을 수 있다. 원저자 설치 스크립트(`install.sh`)는 겹쳐도 덮어쓰므로 그대로 돌리지 않는다.
4. 무엇을 깔지 고르게 한다 — 다섯과 `content-factory` 만, 또는 전부. 겹치는 것은 덮어쓰지 않고 건너뛰는 것이 기본이다. 사용자가 덮어쓰라고 분명히 말한 이름만 덮어쓴다.
5. 고른 폴더만 `~/.claude/skills/<이름>/` 으로 복사한다. 복사한 목록과 건너뛴 목록을 그대로 보여 준다. 실패한 것이 있으면 성공했다고 말하지 않는다. 통과를 지어내지 않는다.
6. 클로드 코드를 껐다 켜야 새 스킬이 잡힌다고 알린다.

클로드 코드 플러그인으로 깔고 싶다고 하면 원저자 README 의 길을 알려 준다.

```
/plugin marketplace add Ootto-AI/claude-content-skills
/plugin install claude-content-skills@ootto-content-skills
```

이 명령은 클로드 코드 안에서 사용자가 직접 친다.

- 「carousel-builder 로 '고객을 놓치는 실수 5가지' 캐러셀 10장」
- 「bio-profile-optimizer 로 내 소개글 고쳐 줘: (지금 소개글)」

분야·대상·목표를 같이 주면 결과가 좋아진다. 결과는 초안이다. 올리기 전에 사용자가 사실을 확인한다.

## 지키는 것

- 가입·로그인·키 입력을 대신 하지 않는다. 키·토큰을 받거나 저장하지 않는다.
- 계정에 글을 올리거나 DM 을 보내는 일은 사용자가 직접 하게 둔다. 그런 도구를 붙이자고 하면 무엇이 계정에서 일어나는지 먼저 설명하고 허락을 받는다.
- 되돌리기 어려운 동작(덮어쓰기 · 지우기)은 하기 전에 확인받는다.
- 조회수·매출이 오른다고 약속하지 않는다.

## 확인 못 함

- 55개 스킬을 전부 돌려 보지는 않았다. 위 다섯과 content-factory 는 스킬 파일을 읽어 무엇을 하는지만 확인했다.
- 플러그인 설치 길(`/plugin install`)이 스킬을 몇 개 싣는지는 재지 않았다. 플러그인 설명에는 13개라고 적혀 있다.
