# 네이버 블로그 상위노출 글쓰기

네이버는 백링크가 아니라 **블로그의 주제 전문성(C-Rank) + 글 한 편의 품질(D.I.A.+) + 직접 경험의 진정성**으로 순위를 매긴다.
이 스킬의 목표: 실제 한국 블로거처럼 따뜻한 ~해요체로 쓰면서, 구조는 네이버 알고리즘이 좋아하는 형태로 만든다.

---

## 0. 작업 순서 (항상 이 순서로)

1. **정보 받기** — 아래 항목을 사용자에게 묻는다. 이미 준 정보는 다시 묻지 않는다.
   - 주제 / 업종 / 지역(지역 글이면)
   - 글 유형: 방문 후기 · 제품 리뷰 · 업체 소개 · 정보성(How-to, 비교, 추천 N곳) 중 무엇인지
   - 직접 경험한 내용: 언제, 무엇을, 가격, 좋았던 점, **아쉬웠던 점**
   - 사진 수와 각 사진 내용(없으면 무엇을 찍을지 안내)
   - 협찬·대가 여부 (내돈내산인지)
   - 블로그의 평소 주제 (주제 일관성 확인용)
2. **키워드 정하기** — 2장 기준으로 메인 키워드 1개 + 세부 키워드 2~3개를 제안하고 확정받는다.
3. **제목 후보 3개** — 3장 규칙대로.
4. **본문 초안** — 4~6장 규칙과 8장 템플릿을 따른다. 사진 자리는 `[사진 N: 무엇을 찍은 사진 / 캡션]`으로 표시.
5. **태그 5~10개**.
6. **발행 전 체크리스트(9장)로 자가 점검** — 통과/미통과를 표로 보여 준다.
7. **사용자에게 꼭 알릴 것**: "초안을 그대로 올리지 말고, 본인 경험·말투로 고쳐 쓰고 직접 찍은 사진을 넣어 주세요." (AI 문장 그대로 발행은 저품질 위험)

사용자가 이미 쓴 글을 주면서 "점검해줘"라고 하면 1~5를 건너뛰고 9장 체크리스트 + 7장 저품질 위험 요소로 진단하고, 고친 버전을 제시한다.

## 1. 네이버 순위 구조 (알고 쓰기)

| 층 | 무엇을 평가 | 글쓴이가 할 일 |
|---|---|---|
| **C-Rank** | 블로그(작성자) 신뢰도 — 주제 집중도, 꾸준함, 반응, 신뢰 | 한 블로그에 한 분야만. 같은 카테고리 글이 쌓일수록(실무상 50편+) 유리 |
| **D.I.A.+** | 글 한 편의 품질 — 체류시간, 직접 작성, 정보성, 경험성, 최신성 | 첫 200자에 핵심, 원본 사진, 구체적 경험, 충분한 분량 |
| **스마트블록 / AiR서치** | 검색어를 세부 의도별 블록으로 쪼개 블록마다 가장 맞는 글을 노출 | 넓은 주제 대신 **세부 의도 하나**를 정확히 겨냥. 소제목·표·리스트로 구조화 |
| **AI 브리핑** | 검색 결과 맨 위 AI 요약 답변 | 첫 문단에 바로 답(역피라미드), 끝에 FAQ 3~5개, 명확한 소제목 |

핵심: 새 블로그·작은 블로그도 **경쟁 적은 롱테일 키워드**에서는 D.I.A. 점수만으로 상위에 오를 수 있다. 그렇게 쌓이면 C-Rank가 오른다.

## 2. 키워드 — 글 쓰기 전에 먼저 정한다

| 종류 | 예시 | 전략 |
|---|---|---|
| 대표키워드 | 강남 맛집, 무선 이어폰 | 검색량·경쟁 모두 큼. 작은 블로그는 피한다 |
| 세부키워드 | 강남 파스타 맛집, 노이즈캔슬링 이어폰 | 글 품질이 좋으면 노려볼 만함 |
| 롱테일 | 강남역 11번출구 파스타 점심, 10만원대 노이즈캔슬링 이어폰 추천 | 경쟁 낮고 의도 명확. **여기서 시작** |

**황금키워드**: 검색량은 있는데 경쟁 글이 적은 키워드.
- 경쟁비 = 월 검색량 ÷ 발행 문서 수 → 0.5 이상이면 유리
- 작은 블로그 목표 구간: 월 검색량 약 300~3,000, 문서 수 5,000 이하(2,000 이하면 더 좋음)

**찾는 법**
1. 네이버 검색창에 씨앗 단어 + 띄어쓰기 → **자동완성**에 뜨는 문구가 실제 많이 찾는 검색어
2. 검색 결과 하단 **연관검색어**로 세부 주제 발굴
3. 검색량·문서 수 확인: 네이버 검색광고 키워드도구(searchad.naver.com), 네이버 데이터랩(datalab.naver.com, 추세 비교), 블랙키위, 키워드마스터(whereispost.com/keyword)
4. **글 1편 = 세부 의도 1개**. "강남 맛집" 대신 "강남역 혼밥 파스타"

사용자가 검색량 데이터를 주지 않으면, 키워드 후보는 "추정"임을 밝히고 위 도구로 확인하라고 안내한다.

## 3. 제목 — 가장 무게가 큰 요소

- **25자 이내** (모바일에서 약 27자 넘으면 잘림)
- **메인 키워드를 맨 앞에**
- 키워드는 2~3개까지, **같은 단어 반복 금지** (저품질 직접 원인)
- 키워드 뒤에 후킹: 숫자, 구체성, 차별점 (`5곳`, `웨이팅 없는`, `3개월 써본`)
- 과장 낚시 표현 금지: `무조건`, `완전 강추`, `역대급`, `최저가`

공식 예시
- 방문 후기: `[지역] + [업종/메뉴] + [후킹]` → `강남역 파스타 맛집 | 웨이팅 없는 골목 이탈리안`
- 제품 리뷰: `[제품명/카테고리] + [사용 기간/관점]` → `갤럭시 버즈3 프로 후기 | 한 달 출퇴근 사용기`
- 정보성: `[주제] + [숫자/해결]` → `전세 계약 체크리스트 7가지 | 계약 전 꼭 확인`
- 업체 소개: `[지역] + [서비스] + [차별점]` → `분당 에어컨 청소 | 분해 세척 전 과정 공개`

## 4. 본문 구조

- **첫 200자**: 메인 키워드 + 핵심 답(결론·위치·가격 등) + (해당 시) 내돈내산/협찬 표기. 가중치가 가장 크다.
- **키워드 빈도**: 본문 전체에 메인 키워드 **6~12회**, 자연스럽게. 세부 키워드 2~3개를 첫 문단·소제목 1개 이상·사진 캡션·마무리에 나눠 넣는다. 10회를 크게 넘기면 도배로 본다.
- **분량** (공백 제외):
  - 정보성 글 1,500~2,000자
  - 후기·리뷰 1,000자 이상 + 사진 많이
  - AI 브리핑 노리는 글 2,000자 이상
- **모바일 가독성**:
  - 문단은 2~4문장
  - 300~500자마다 소제목
  - 핵심 정보(가격·시간·스펙)는 **굵게**
  - 비교·메뉴·스펙은 표, 장단점·추천 대상은 리스트
  - 소제목 앞 이모지 활용 (`📍 위치` `💰 가격` `⏰ 영업시간` `✅ 장점` `⚠️ 아쉬운 점`)
- **말투: ~해요체**. 따뜻하고 1인칭. `~합니다`체는 보도자료처럼 읽힌다.
- **경험성**: 구체적 날짜·요일·시간, 상황, 직접 느낀 점, **솔직한 단점 하나 이상**. 장점만 나열하면 광고로 읽힌다.

---

## 5. 사진·영상·지도

- **직접 찍은 원본 사진 10장 이상** (최소 6장, 경쟁 심한 키워드는 20~40장). 가장 강한 진정성 신호.
- 다른 글에 쓴 사진 재사용, 인터넷 이미지·업체 제공 사진 그대로 사용 금지 (중복 이미지 감점). 가볍게 보정해서 올린다.
- 사진마다 키워드가 들어간 **설명 캡션** (파일명·"사진1" 같은 무의미한 캡션 금지).
- 1분 이상 짧은 영상을 넣으면 체류시간이 오른다.
- 매장·장소 글이면 **네이버 지도(장소) 첨부** 필수 — 방문 검증 + 네이버 지역 검색 연결.

## 6. 진정성·광고 표기 (법적 의무 포함)

- 대가(현금, 제품, 무료 식사·서비스, 제휴 수수료, 지속적 관계)를 받았다면 **제목 또는 글 맨 앞**에 표기한다. 중간·끝에 숨기면 안 된다 (2024년 12월 공정위 지침 개정).
  - 협찬: `[협찬] 이 포스팅은 OO으로부터 제품을 제공받아 작성되었습니다.`
  - 내돈내산: `✅ 내돈내산 | 어떠한 대가도 받지 않고 직접 구매한 후기예요.`
- 내돈내산은 사실일 때만 쓴다. 사실이면 신뢰도·체류시간에 유리하다.
- 사용자가 협찬 여부를 말하지 않았으면 반드시 물어본다.

## 7. 저품질 피하기

**원인**
- 복사·붙여넣기, 업체가 준 원고 그대로 사용 (유사문서 탐지)
- 제목 키워드 반복, 본문 키워드 도배
- 상업 단어 남발: `최저가`, `강력추천`, `무조건`, `할인 이벤트` 반복
- 외부 링크 과다, 이미지 재사용
- 블로그 주제와 무관한 글 섞기
- 몰아서 발행 후 장기간 방치
- 매크로·자기 검색 클릭, 무의미한 서로이웃 대량 추가
- 협찬 표기 숨기기
- **AI 생성 글을 그대로 발행**
- 보험·대출·의료·성형 등 고위험 업종은 더 엄격하게 본다

**자가 진단**
- 내 글 제목을 큰따옴표로 묶어 네이버 검색 → 상단에 안 보이면 누락 의심
- 본문 중간 고유 문장을 큰따옴표로 검색 → 다른 글이 나오면 중복 문서
- 무료 점검 도구: 블덱스, 판다랭크, 라온픽 등

**회복**: 최근 글 중 문제 글 비공개/삭제 → 광고성 글 정리 → 2~4주간 순수 정보성 글 발행 → 키워드 표현 다양화. 보통 3~4개월 걸린다.

**오해 바로잡기**
- 광고 글 자체가 저품질 원인은 아니다. 정보 없는 광고 + 높은 이탈 + 키워드 남용이 문제다. 광고 글에도 실제 정보를 충분히 넣는다.
- **태그는 순위에 거의 영향이 없다** (인스타와 다름). 관련 있는 것 5~10개만.

## 8. 글 템플릿 (유형별 뼈대)

### A. 방문 후기 / 업체 소개
```
[제목] 지역+업종+후킹, 25자 이내

[첫 문단 ≤200자] 메인 키워드 + 위치/핵심 특징 + 내돈내산·협찬 표기

📍 기본 정보 (리스트)
- 위치 / 영업시간 / 주차 / 가격대 / 예약
[네이버 지도 첨부]

🚶 방문 경험 (언제·어떤 상황·첫인상, 구체적으로)
[사진 2~3장 + 캡션]

⭐ 핵심 메뉴·서비스 솔직 후기 (가격 굵게, 장점 + 아쉬운 점)
[사진 3~5장 + 캡션]

💬 이런 분께 추천해요 (리스트 3~4개 — 스마트블록 세부 의도 매칭)

[마무리] 한 줄 요약 + 관련 글 내부 링크 + 댓글 유도 질문
[태그 5~10개]
```

### B. 제품 리뷰
```
[제목] 제품명+후기 관점(사용 기간/용도), 25자 이내

[첫 문단 ≤200자] 결론 먼저 (추천/비추천 대상) + 사용 기간 + 내돈내산·협찬 표기

📦 제품 기본 정보 (표: 가격, 주요 스펙, 구매처)
✅ 좋았던 점 (실사용 장면과 함께) [사진]
⚠️ 아쉬운 점 (솔직하게 1~3개) [사진]
🆚 비슷한 제품과 비교 (표)
💬 이런 분께 추천 / 비추천
❓ 자주 묻는 질문 3~5개
[마무리] 요약 + 댓글 유도
```

### C. 정보성 (방법, 체크리스트, 추천 N곳, 비교)
```
[제목] 주제+숫자/해결, 25자 이내

[도입 — 역피라미드] 첫 문단에 바로 답. 이 글에서 무엇을 알 수 있는지 한 줄.

📊 요약 표 (전체를 한눈에)

소제목 ① ~ ⑤ (항목마다: 설명 + 직접 경험/근거 + 사진 1~3장)

❓ 자주 묻는 질문 (AI 브리핑용, 실제로 사람들이 묻는 말투로 3~5개)
Q. ~ ? A. ~ 

[마무리] 핵심 요약 + 관련 글 링크 + 댓글 유도 질문
```

마무리 댓글 유도 예: `여러분은 어떻게 하고 계세요? 댓글로 알려주세요 😊`
반응 가치: 댓글 > 스크랩 > 공감. 일주일 2~3회 같은 주제로 꾸준히 발행하는 것이 매일 얕게 쓰는 것보다 낫다.

## 10. 지키는 원칙

- 사용자가 겪지 않은 경험, 확인되지 않은 가격·영업시간·스펙을 지어내지 않는다. 모르는 값은 `[확인 필요: 영업시간]`처럼 비워 둔다.
- 경쟁 글을 참고하더라도 문장을 베끼지 않는다. 구성과 빠진 정보만 참고해 더 나은 글을 만든다.
- 순위 수치(가중치 비율, 글 수 기준 등)는 실무자 경험치이며 네이버 공식 발표가 아님을 필요할 때 밝힌다.
